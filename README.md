# سایت رزومه رایان + پنل مدیریت (نسخه Vercel)

طراحی و ظاهر سایت اصلی **دست‌نخورده** باقی مانده است. یک پنل مدیریت کامل اضافه شده که با آن می‌توانید همه‌چیز را تغییر دهید و روی سایت نمایش داده شود.

## امکانات پنل

| بخش | توضیح |
|---|---|
| داشبورد | نمای کلی، آمار پیام‌ها و رنگ فعلی سایت |
| نظرات و پیام‌ها | دیدن پیام‌های فرم «ارتباط با من»، جست‌وجو، خوانده‌شده/نشده، حذف، پاسخ ایمیلی |
| ظاهر و تم | تغییر رنگ کل سایت (هر رنگی که بخواهید) + پالت‌های آماده + پیش‌نمایش زنده |
| محتوای سایت | عنوان سایت، معرفی کوتاه، متن‌های «درباره من»، مهارت‌ها (نام و درصد)، فوتر |
| پروفایل و تصاویر | نام نمایشی، آپلود عکس پروفایل، آپلود لوگو، پس‌زمینه هدر |
| تماس و شبکه‌ها | تلفن، ایمیل، آدرس، سن، زبان، اکانت‌های تلگرام، اینستاگرام، واتساپ، توییتر و… |
| امنیت | تغییر نام کاربری و رمز عبور |

## آپلود روی Vercel — قدم به قدم

### روش ۱: از طریق GitHub (پیشنهادی)

1. فایل‌های این پوشه را در یک ریپازیتوری GitHub آپلود کنید (پوشه `node_modules` و `.data` را آپلود نکنید).
2. وارد [vercel.com](https://vercel.com) شوید → **Add New… → Project** → ریپو را Import کنید.
3. قبل از Deploy هیچ تنظیم خاصی لازم نیست؛ فقط **Deploy** را بزنید.
4. حالا **Vercel Blob** را اضافه کنید (برای ذخیره تنظیمات، پیام‌ها و آپلود عکس‌ها):
   - از منوی بالای پروژه → تب **Storage** → **Create Database** → **Blob** را انتخاب کنید.
   - نام دلخواه بدهید → **Create** → سپس **Connect to Project** و همان پروژه را انتخاب کنید.
5. یک بار دیگر از تب **Deployments** روی آخرین دیپلوی **Redeploy** بزنید (تا توکن Blob به توابع وصل شود).
6. تمام! سایت روی `https://your-project.vercel.app` و پنل روی `https://your-project.vercel.app/admin`

> اگر Blob را وصل نکنید، سایت و پنل بالا می‌آیند ولی ذخیره تنظیمات/پیام‌ها در حالت ابری کار نمی‌کند. این قدم را حتماً انجام دهید.

### روش ۲: با خط فرمان Vercel

```bash
npm install
npx vercel login
npx vercel          # دیپلوی
npx vercel --prod   # دیپلوی نهایی
```
سپس Blob را از داشبورد Vercel مثل روش ۱ (قدم ۴) اضافه کنید.

## اجرای محلی (روی کامپیوتر خودتان)

```bash
npm install     # نصب وابستگی‌ها
npm run build   # ساخت پنل (پوشه admin) — از قبل ساخته شده، فقط برای تغییرات آینده
node server.js  # اجرای سایت + پنل + API
```

- سایت: `http://localhost:3000`
- پنل: `http://localhost:3000/admin/`

در حالت محلی داده‌ها در پوشه `.data` ذخیره می‌شوند (این پوشه را آپلود نکنید).

## سوالات پرتکرار

**تغییرات چه زمانی روی سایت دیده می‌شود؟**
تا حداکثر یک دقیقه بعد از ذخیره (به‌خاطر کش لبه). با رفرش صفحه (Ctrl+Shift+R) فوراً می‌بینید.

**«نظرات کاربران» چیست؟**
پیام‌هایی که بازدیدکنندگان از فرم «ارتباط با من» ارسال می‌کنند، مستقیم به پنل می‌آیند و در بخش «نظرات و پیام‌ها» می‌بینید.

**عکس‌ها کجا ذخیره می‌شوند؟**
در Vercel Blob (فضای ابری خود پروژه). در حالت محلی در پوشه `.data`.

**رمز را فراموش کردم چه کنم؟**
اگر رمز را از پنل عوض کرده باشید: در Vercel یک متغیر محیطی جدید `ADMIN_SECRET` با یک عبارت تصادفی بسازید و Redeploy کنید، سپس با `ADMIN_USERNAME`/`ADMIN_PASSWORD` (اگر تنظیم نکرده‌اید: rayan1234/123456) وارد شوید. اگر باز نشد، فایل/آیتم `settings.json` را از Blob حذف کنید و دوباره وارد شوید.

**آیا ظاهر سایت تغییر کرده؟**
نه. همه تغییرات از طریق اسکریپت همگام‌سازی روی همان HTML/CSS اصلی اعمال می‌شود؛ اگر پنل چیزی ذخیره نکرده باشد، سایت دقیقاً مثل قبل است.
